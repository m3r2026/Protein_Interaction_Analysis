# Protein Interaction & Conservation Analysis Pipeline

## 概要
PDB構造データからタンパク質-DNA（またはタンパク質間）の相互作用界面を特定し、進化的な保存度（Conservation Score）と統合して解析する自動化パイプラインです。

## 主な機能
- **構造解析**: SASA（溶媒接近可能表面積）を用いたBSA（埋没表面積）の計算。
- **相互作用判定**: 原子間距離に基づく水素結合、疎水性相互作用等の自動分類。
- **進化解析**: BLAST検索とMAFFTを用いた多重配列整列（MSA）の実行、およびシャノン・エントロピーによる保存度算出。
- **可視化準備**: 保存度スコアをPDBのB-factor列に書き込み、PyMOLでの色分け表示を可能にします。

## 動作環境
- **OS**: Windows 10/11 (MAFFTの呼び出しに `.bat` を使用するため)
  ※今後、Windows以外にも対応可能とするため更新予定です。
- **Language**: Python 3.x
- **Dependencies**: Biopython, Pandas, NumPy

## 使用方法
1. 本リポジトリをクローンまたはダウンロードします。
2. MAFFT公式サイトからWindows版をダウンロードします。
3. bin/mafft-win/ フォルダを新規作成し、解凍したMAFFTの中身をすべて配置してください。
4. `targets` リストに解析したいPDB IDとチェーンを指定します。
6. ノートブックを実行すると、最終的な解析結果がCSVおよび可視化用PDBとして出力されます。

## 注意事項
- 本プログラムは残基番号が連続している構造を想定しています。
- 外部データベース（NCBI）へのアクセスを含むため、実行にはインターネット環境が必要です。
